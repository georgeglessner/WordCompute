How to Play

Find the 5-letter word and the operators between its letters that reach the target number.

Every letter has a value: A is 1, B is 2, up to Z at 26. Letters and operators alternate, so each guess is a word with an operator in every gap.

S19−C3+O15×R18+E5

Standard order of operations applies, so S−C+O×R+E is 19 − 3 + (15 × 18) + 5 = 291. The value of each guess appears beside its row.

  • S is in the right spot.
  • C is in the answer but in a different spot.
  • O is not in the answer.

Operators are scored the same way against the answer's operators. Tap a tile or use the arrow keys to move between slots.
